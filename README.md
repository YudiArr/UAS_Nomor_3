Dengan semakin meningkatnya kesadaran masyarakat akan “clean” eating dan konsumsi “real food” dibandingkan makanan cepat saji yang seringkali diulas mengandung berbagai senyawa yang tidak baik bagi tubuh manusia, maka tingkat belanja sayuran dan buah segar meningkat tajam. Namun sayangnya sayuran dan/atau buah yang dibeli biasanya tidak bertahan lama sedangkan dengan padatnya aktivitas di kota, maka hal ini menjadi ide startup baru yang akan diberi nama Fresh Harvest Organics (FHO). FHO dalam hal ini akan menyediakan katalog berupa sayuran, buah, maupun daging dan bahan alami lainnya yang dapat dipesan hingga 3 jam sebelumnya. Metode pengiriman adalah instan (1jam), dan juga next day service. Untuk saat ini layanan FHO adalah maksimal 25 km karena FHO belum memiliki cabang. FHO juga menyediakan informasi berbagai resep masakan dan user dapat langsung klik membeli bahan untuk dapat langsung mempraktekkan resep yang disediakan tersebut. Pembayaran wajib dilakukan sebelum penyelesaian pemesanan dan ditangani oleh Payment Gateway. Perhitungan jarak dilakukan melalui GojekAPI yang sekaligus mengkalkulasikan ongkos kirim. Khusus untuk next day service dilayani oleh kurir toko sehingga ongkos kirimnya dihitung flat sebesar Rp. 20.000,- per pengiriman.

Dengan demikian, maka sistem FHO akan digunakan user dan admin dengan fitur yang dapat mengakomodir penjelasan di atas.


Pertanyaan
Berdasarkan studi kasus Fresh Harvest Organics (FHO) di atas, buatlah program aplikasi tersebut, dengan minimal memiliki fitur yang dijelaskan. Fitur dapat dilengkapi atau ditambahkan bila dirasa perlu. Program yang dibuat harus dalam bentuk code Java dengan menerapkan implementasi konsep: Inheritance, Encapsulation, Polymorphism, Abstract Class, dan Interface. Jawaban berupa code dan sertakan screenshot program ketika dijalankan.

Catatan: Khusus untuk bagian pembayaran, tidak perlu integrasi nyata dengan Payment Gateway atau third party, cukup diasumsikan sukses setelah memilih.
